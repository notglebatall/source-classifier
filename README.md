# Source Classifier

LangGraph-агент для классификации источников по URL. `run.ipynb` построчно читает URL из XLSX, вызывает агента и после обработки каждого URL записывает ответ в колонку `labels`.

## Результат

```python
class ClassifiedSource(BaseModel):
    input_url: str
    canonical_url: str | None
    source_name: str | None
    geography: list[str]
    topics: list[str]
    source_type: str
    evidence_urls: list[str]
    explanation: str
    classified: bool
```

Категории выбираются из закрытой таксономии. Если данных недостаточно, агент возвращает `classified=false`, не угадывая метки.

## Схема работы

```mermaid
flowchart TD
    A[Входной URL] --> B[Инициализировать исследование<br/>попытки: 0 из 5]
    B --> C[Выбрать URL для открытия]
    C --> D[Открыть страницу<br/>и увеличить счётчик попыток]
    D --> E{Страница доступна?}

    E -- Да --> F[Определить источник и извлечь сведения]
    F --> G[Обновить состояние исследования:<br/>название, основной URL, география,<br/>тематики, тип и доказательства]
    G --> H{Данных достаточно<br/>и нет существенных противоречий?}

    H -- Да --> I[Сформировать классификацию]
    H -- Нет --> J{Остались попытки?}
    J -- Нет --> K[Сформировать результат<br/>или вернуть classified=false]
    J -- Да --> L[Определить, каких сведений не хватает]
    L --> M{Есть информативная ссылка<br/>на сайте?}
    M -- Да --> C
    M -- Нет --> N{Остались попытки<br/>и поисковые запросы?}

    E -- Нет --> N
    N -- Да --> O[Выполнить веб-поиск]
    N -- Нет --> K
    O --> P{Найдена подходящая страница?}
    P -- Да --> C
    P -- Нет --> K
```

Агент оценивает источник в целом, а не тему одной публикации. Исходный URL входит в лимит из пяти попыток открытия; цепочка HTTP-редиректов считается одной попыткой. После каждой доступной страницы агент обновляет накопленные сведения и выбирает следующий URL под конкретный пробел в данных. Поисковый запрос не расходует лимит страниц, но на один источник допускается не более двух запросов. Открытая страница из поисковой выдачи расходует попытку на общих основаниях.

Агент завершает исследование раньше лимита, если источник однозначно определён и для выбранных меток достаточно доказательств. В `evidence_urls` попадают только страницы, которые использованы при вынесении вердикта. Если источник не удалось идентифицировать или ключевые метки нельзя подтвердить, агент возвращает `classified=false`.
